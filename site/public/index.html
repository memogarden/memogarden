Memo Garden 🌱

A personal memory system for financial transactions.

Memo Garden captures and reconciles financial transactions as beliefs, backed by immutable evidence — emails, invoices, statements — ingested from the owner's own Gmail. It is a personal-use application: for now it is operated by and for a single person, and there are no public accounts.

This website is a static landing page. It collects no data, sets no cookies, and serves no trackers. The application itself runs privately on the operator's own machine.
