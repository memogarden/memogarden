Privacy Policy

Memo Garden v0 · Effective date: 2 November 2026 · Contact: ngjunsiang@gmail.com

Memo Garden is a personal-use application. It is operated by a single individual (Ng Jun Siang, the owner of this website) for their own private use. There are no public accounts, no other users, and no sign-ups. This policy describes how the operator's own data is handled.

What the application is

Memo Garden is a personal memory system for financial transactions. It ingests email from the operator's own Gmail mailbox and stores it — together with extracted attachment metadata — in a private, local database as searchable, immutable records.

What data is accessed and collected

  • Google account identity: the email address of the authorized Google account and an internal user identifier, obtained via OAuth consent.
  • Gmail data (read-only): message metadata, headers, bodies, and attachment names/hashes from the authorized account's own mailbox, read through the Gmail API with the read-only scope (gmail.readonly). Attachments are recorded as metadata (filename, size, content hash); binaries, where stored, are kept only in the operator's private local store.

Where data is stored

All ingested data is stored locally on the operator's own machine (SQLite databases and a local file store). It is not uploaded to this website or to any cloud service operated by a third party. This website itself is a static page: it collects no data, sets no cookies, uses no analytics, and serves no trackers.

What we do not do

  • We do not sell, rent, share, or transfer personal data to third parties.
  • We do not show advertisements.
  • We do not collect data about any other person: the only mailbox read is that of the operator, with the operator's own explicit consent.
  • We do not use Gmail data for advertising, model training, or any purpose other than the personal record-keeping described above.

Gmail API — Limited Use disclosure

Memo Garden's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Ingested data is retained locally for as long as the operator finds it useful, and is deleted when the operator deletes the local database or individual records. The operator can revoke the application's access to their Google account at any time via Google Account — Third-party access. Revoking access stops all future reads; locally stored data is under the operator's sole control and is not retrievable by anyone else.

Changes to this policy

If Memo Garden ever stops being a single-user, personal application, this policy will be updated before any new data practices take effect.
